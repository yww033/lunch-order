# Lunch Order System

A responsive lunch ordering web app for teams with analytics dashboard.

## Demo
https://yww033.github.io/lunch-order/

## Features
- Responsive ordering interface
- Department-based order grouping
- Order summary and payment status
- Google Sheets backend
- Data visualization dashboard (Looker Studio)

## Analytics Dashboard
The system integrates with Google Looker Studio to provide real-time analytics including:

- Order distribution by department
- Popular menu items
- Daily order trends
- Payment status overview

## Tech Stack
- HTML
- Bootstrap
- JavaScript
- Google Apps Script
- Google Sheets
- Looker Studio
